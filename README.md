# La Gran Pata Gaucha

Sitio web desarrollado para La Gran Pata Gaucha, un emprendimiento gastronómico de Concepción del Uruguay, Entre Ríos, con 17 años de trayectoria.

## Descripción

La página presenta nuestros principales servicios y productos para eventos, como patas de ternera, bondiolas desmenuzadas, costillares, picadas, empanadas y salsas caseras.

## Tecnologías utilizadas

- HTML
- CSS
- Bootstrap 5
- Git y GitHub

## Secciones del sitio

- Inicio
- Nosotros
- Productos
- Servicios
- Contacto por WhatsApp

## Objetivo del proyecto

Desarrollar un sitio web para La Gran Pata Gaucha que permita presentar el emprendimiento, sus productos y servicios gastronómicos, mejorar su presencia digital y facilitar el contacto con potenciales clientes.
